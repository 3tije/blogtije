BLOG TIJE — LOGIN FINAL

1. Di Apps Script → Project Settings → Script Properties pastikan ada:
   STUDIO_PASSWORD = password pilihan Bro
   SESSION_SECRET = rahasia acak (dibuat otomatis oleh setupBlogTije)
   GEMINI_API_KEY = key layanan AI (tetap hanya di server)

2. Password login TIDAK disimpan di frontend.
3. Setelah login berhasil, browser menyimpan session token selama masa sesi (default 30 hari).
4. URL backend cukup dikonfigurasi satu kali di assets/config.js:
   API_URL = URL Web App Apps Script yang berakhiran /exec

Jangan masukkan API key layanan AI ke config.js atau GitHub.
